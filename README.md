# Midnight Bloom — TOV4R

A pink particle lily inspired by the supplied flower animation. The stem grows, four leaves unfold, and six petals open under fine orbital trails.

Open `index.html` directly in any modern browser. No installation, build, external libraries, or network requests are needed.

## Controls
- Replay restarts the growth animation.
- Pause / Play controls motion.
- Move the pointer to gently rotate the flower.
- Fullscreen is available when supported by the browser.
- Reduced-motion preferences show the finished flower paused; press Play to animate.

## GitHub Pages
Publish the repository from Settings → Pages → Deploy from a branch → main → / (root).

Files: `index.html`, `style.css`, `script.js`, and `.nojekyll`.
